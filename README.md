# Mirror Lab Detailing

Сайт детейлинга Mirror Lab, Владивосток. Обычный статический сайт: HTML, CSS и JavaScript без сборки, открывается в любом браузере.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Тексты и структура всех разделов |
| `js/prices.js` | Цены в калькуляторе |
| `js/main.js` | Анимации, мойка машины, калькулятор, окно записи |
| `css/style.css` | Оформление, цвета, тёмная и светлая тема |
| `img/` | Фото машины (чистая и грязная), фото для декора |

## Как поменять цены

1. Открой `js/prices.js`.
2. Найди услугу и поменяй числа: `car` для легковых, `suv` для джипов, минивэнов и пикапов.

3. Сохрани файл и загрузи его на хостинг.

Цены в бегущей строке, в выносках возле машины и в блоке «Блеск» записаны прямо в `index.html`, их ищи по значку ₽.

## Как поменять телефон

Номер встречается в `index.html` в нескольких местах (`+7 924 430-45-51` и `tel:+79244304551`) и один раз в `js/main.js` (кнопка «Скопировать»). Меняй через поиск с заменой.

## Как вставить фото работ

В `index.html` найди блок `<!-- WORKS -->`. В каждой карточке есть две заглушки:

```html
<div class="ph after">...Фото «после»</div>
<div class="ph before">...Фото «до»</div>
```

Положи фото в `img/` и замени содержимое заглушки на картинку, например:

```html
<div class="ph after"><img src="img/work1-after.webp" alt="Салон после химчистки"></div>
```

## Как выложить в интернет

Сайт состоит из файлов, их нужно положить на хостинг.

1. Купить домен (например, на Рег.ру) на владельца бизнеса. Для доменов .ru нужно подтверждение через Госуслуги.
2. Взять тариф на российском хостинге (Beget или Timeweb).

3. В панели хостинга загрузить в папку сайта (`public_html`) всё содержимое этого репозитория: `index.html` и папки `css`, `js`, `img`.
4. Привязать домен и включить бесплатный SSL-сертификат.

GitHub Pages тоже умеет показывать такие сайты, но из России он открывается нестабильно, поэтому для клиентов лучше российский хостинг.
